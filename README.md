# 🍳 Recipe Explorer

Recipe Explorer is a simple and responsive recipe application built using React JS and Tailwind CSS.

Users can search for recipes, explore different food categories, and view recipe details.

## ✨ Features

- Browse different recipes
- Search recipes by name
- Filter recipes by category
- View complete recipe details
- View ingredients and cooking instructions
- Watch recipe videos when available
- Save favorite recipes

## 🛠️ Technologies will Use

- React JS
- Tailwind CSS
- React Icons
- Fetch API / Axios
- TheMealDB API

## 🔗 API

This project uses TheMealDB public API to fetch recipe data.
